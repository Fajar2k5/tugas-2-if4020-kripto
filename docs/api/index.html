Dokumentasi API TUNG-128

Referensi fungsi Python untuk enkripsi berkas, autentikasi, dan analisis.

DeskripsiEnkripsiEnvelopeAnalisisContoh
Jenis API: fungsi-fungsi ini adalah API Python yang dipanggil langsung di program desktop, bukan endpoint HTTP/REST.

1. Deskripsi API

API menyediakan operasi enkripsi/dekripsi TUNG-128, pembungkusan berkas dengan tag integritas, dan pengukuran statistik ciphertext. Fungsi utama integritas dapat diimpor langsung dari paket keris128; operasi cipher tersedia di keris128.tung dan analisis di keris128.analysis.

Data berkas direpresentasikan sebagai bytes. Kunci yang diterima implementasi saat ini harus tepat 16 byte. Mode yang tersedia adalah "ECB", "CBC", "CFB", "OFB", dan "CTR". Fungsi mode menerapkan padding PKCS#7.

2. Enkripsi dan dekripsi langsung

keris128.tung.encrypt(data, key, mode, iv=None) -> bytes

ParameterTipeKeterangan
databytesPlaintext, dapat berupa teks terenkode atau data biner.
keybytesKunci master tepat 16 byte pada API saat ini.
modestrNama mode: ECB, CBC, CFB, OFB, atau CTR (huruf besar).
ivbytes | NoneIV/counter 16 byte untuk CBC, CFB, OFB, dan CTR. Abaikan pada ECB.
KeluaranbytesCiphertext yang sudah diberi padding. Untuk penyimpanan berintegritas, gunakan seal.

keris128.tung.decrypt(data, key, mode, iv=None) -> bytes

Parameter masukan sama seperti encrypt, dengan data berupa ciphertext berpadding. Keluaran adalah plaintext setelah padding divalidasi dan dilepas. Fungsi langsung ini tidak memverifikasi tag integritas.

Envelope berintegritas

keris128.seal(data, key, mode, iv=None) -> tuple[bytes, bytes | None]

ParameterTipeKeterangan
databytesPlaintext yang akan dienkripsi.
keybytesKunci master tepat 16 byte.
modestrSalah satu dari lima mode yang didukung.
ivbytes | NoneIV/counter 16 byte. Jika None pada mode selain ECB, API membuat IV acak.
Keluarantuple[bytes, bytes | None](envelope, iv_efektif). Envelope berisi penanda format, mode, IV, ciphertext, dan tag HMAC-SHA-256.

keris128.open_sealed(envelope, key) -> tuple[bytes, str, bytes | None]

Masukan envelope: bytes dan key: bytes (16 byte). Keluaran adalah (plaintext, mode, iv). Tag diperiksa sebelum dekripsi. Format salah, kunci salah, atau data termodifikasi akan menghasilkan ValueError.

Analisis keamanan

keris128.analysis.byte_entropy(data) -> float

Masukan data: bytes; keluaran entropi Shannon dalam bit per byte, rentang 0–8. Data kosong menghasilkan 0.

keris128.analysis.byte_histogram(data) -> list[int]

Masukan data: bytes; keluaran daftar 256 bilangan bulat. Indeks daftar adalah nilai byte (0–255), sedangkan nilai elemennya frekuensi kemunculan.

keris128.analysis.avalanche_bits(left, right) -> tuple[int, int, float]

Masukan dua bytes dengan panjang sama; keluaran (bit_berubah, total_bit, persentase). Panjang berbeda menghasilkan ValueError.

keris128.analysis.analyze_modes(data, key, iv) -> dict[str, dict[str, float]]

Menghitung entropi plaintext/ciphertext dan panjang byte untuk kelima mode. Masukan: data: bytes, key: bytes 16 byte, iv: bytes 16 byte (diabaikan untuk ECB). Keluaran memakai nama mode sebagai kunci; setiap nilai berisi plaintext_bits_per_byte, ciphertext_bits_per_byte, plaintext_bytes, dan ciphertext_bytes.

keris128.analysis.avalanche_modes(data, key, iv) -> dict[str, dict[str, float]]

Masukan sama seperti analyze_modes. Keluaran berisi tiap mode dan ukuran perubahan ciphertext untuk pembalikan satu bit plaintext serta satu bit kunci: plaintext_changed_bits, plaintext_percent, key_changed_bits, dan key_percent.

3. Contoh penggunaan API

from keris128 import seal, open_sealed

plaintext = b"Contoh pesan TUNG-128"
key = bytes.fromhex("00112233445566778899aabbccddeeff")

# CBC dengan IV yang dibuat otomatis oleh seal
envelope, iv = seal(plaintext, key, "CBC")
hasil, mode, iv_tersimpan = open_sealed(envelope, key)

assert hasil == plaintext
assert mode == "CBC"
assert iv == iv_tersimpan

4. Penjelasan tambahan

  • Jangan memakai ulang IV pada CBC/CFB/OFB atau counter/nonce pada CTR dengan kunci yang sama.
  • Gunakan seal/open_sealed untuk berkas agar mode, IV, ciphertext, dan tag integritas terikat bersama.
  • API ini adalah fungsi Python lokal, bukan layanan jaringan; halaman ini hanya dokumentasi publik statis.
